# ConfigUSA Corporate Experience

Build a corporate website in React and Tailwind CSS for ConfigUSA. Capture the official logo, certifications, and brand identity from https://config-usa-gold.vercel.app/ and follow the attached ConfigUSA CEO Blueprint (configusa_ceo_blueprint.md). Generate high-fidelity background images for each section according to the prompts and content specified in the blueprint (corporate hero, SAP and Workday enterprise platforms, industry verticals, global footprint across US, India, and Canada, delivery proof, and careers). Implement the complete navigation, dropdowns, inner page views, interactive talent inquiry and contact forms with deep navy (#10243A), soft ivory, and subtle champagne gold (#B59A62) styling.
