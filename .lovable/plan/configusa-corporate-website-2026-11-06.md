# ConfigUSA corporate website

## Experience
- Replace the homepage placeholder with a polished, responsive ConfigUSA corporate site using the requested deep navy, ivory, and champagne-gold identity.
- Build a clear desktop and mobile navigation with grouped dropdowns, a prominent talent inquiry action, and shared footer.
- Include the homepage and dedicated views for company/about, differentiators, leadership, staffing, MSP/VMS, technology consulting, SAP, Workday, cloud/infrastructure, AI/data/digital engineering, industries, global presence, careers, and contact.
- Use purpose-made enterprise photography for the requested sections, with reusable image treatments and responsive layouts.
- Implement interactive contact/talent inquiry forms with client-side validation, confirmation states, and a resume-upload interface; avoid claiming delivery or storage until a service is connected.
- Use verified brand assets and certifications from the reference site, and avoid publishing unverified client metrics, contact details, or executive details.

## Technical approach
- Keep the homepage at `/`; use TanStack Start file-based routing and a reusable slug-based route for the inner pages.
- Define palette values as semantic design tokens and use existing UI controls.
- Keep form handling in the frontend, with explicit submission feedback and no invented backend behavior.
- Add route-specific metadata and a small routing/form validation test where appropriate.
